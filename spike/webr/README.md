# webR feasibility spike (throwaway; not part of powerkit)

Run on GitHub only, by pushing this branch (`.github/workflows/webr-spike.yaml`).
It checks which foundation packages install in webR, and times E2 and E10
natively and in webR (Node and headless Chromium). Results: the job log and
the `webr-spike-results` artifact. Findings are written up in
`docs/hosting-options.md`. This branch is never merged.
