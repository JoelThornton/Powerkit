Powerkit home

Run Powerkit on your computer

The same interface can open in your browser while the calculations use your own processor and memory. This avoids using Posit's computing time for those calculations. You do not need a Posit account.

Development prototype. Results are not fully validated. Please do not use Powerkit to plan real studies yet. A numbered pre-release is a version you can identify, not a scientific approval.

Download the complete app

  1. Install R using the Windows and Mac setup guide. The first setup can take tens of minutes and needs an internet connection.
  2. Open Powerkit releases, choose a numbered version and download its Source code (zip). This includes the interface, engine, launcher and recorded package versions. Do not use GitHub's main-branch ZIP for a study you need to keep reproducible.
  3. Extract the ZIP. In R, run source(file.choose()) and choose run_powerkit.R in that folder. It installs the recorded dependencies and opens the app.

This is an R-based download, not yet a one-click desktop installer. After installation, calculations run locally; setup, optional update checks and optional feedback need internet access. Close the app by stopping it in R, not only by closing the browser tab.

Current launchers retry interrupted package downloads and use a public CRAN mirror while preserving the recorded versions. If an older download reports “Connection was reset”, see the connection-recovery instructions. A network retry does not fix a missing compiler or an unavailable package version.

Keep updates under your control

  1. Save your unfinished draft or completed project before changing versions. Keep your files outside the application folder.
  2. Stop Powerkit. In R, run source(file.choose()) and choose check_powerkit_updates.R from the downloaded folder. It contacts the public GitHub release list and reports a newer numbered version if found. It sends no study answers and installs nothing. A failed check does not stop local calculations.
  3. If you choose to update, download the new numbered ZIP into a separate folder, restart R, then start its launcher. Keep the old folder and your project files. Do not mix an old interface with a newer engine.
  4. Open a copy of your saved project. Check its recorded version and assumptions before rerunning: a method correction can legitimately change the answer. Archived versions and their recorded dependencies support reproduction; package servers may still change or disappear.

Update checks are optional. Nothing silently changes the software used by an open study. Prototype releases can be listed by the checker, and are identified as such. If your older download has no update-check file, use the releases page directly.

CRAN and browser-only versions

The planned CRAN package is the calculation engine. Installing the engine alone does not install this interface or a desktop application. Powerkit is not yet on CRAN. Until a release is accepted, use the numbered full-app download above.

A version running entirely inside your browser could also use your processor without installing R, but it has not been built or tested. It cannot yet be advertised as supporting all of Powerkit's packages and background simulations.
