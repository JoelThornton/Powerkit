* Study plans: `write_study_plan()` takes `settings` (the plan's `alpha` and `power` for every analysis, each between 0 and 1) and `read_study_plan()` returns them; written only when given, so older files and older versions are unaffected. The app sets them once on a plan's page and starts each analysis added from the plan with them, and the plan page offers "I know my analysis" (the searchable list) beside "Help me choose an analysis" (queue item 29).
