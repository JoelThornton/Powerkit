* Replication plans (app): the criterion that can show absence is always one planned for no effect (the Bayes factor t-test for no effect where the design has one, else the equivalence test); "show it is absent" uses the Bayes factor t-test for no effect for a Bayesian t-test original; the planner asks for the smallest effect before running when an equivalence test has no d33; criteria the original can't give are greyed out; a correlation's Bayes factor original is redirected at once; the chances at a sample size you could recruit are shown in view; write-up labels give the threshold instead of "at your threshold"; headline and table brackets no longer double; the between-study SD note again says the presets are illustrations (Kenny & Judd, 2019); the 1-df ANOVA note says BUCSS appears only with a p-value criterion. The conceptual-replication button now applies its settings to a 1-df ANOVA original (it passed too few fields to tell a 1-df effect from one with several, so nothing changed while the page said "Done"), and the study design table asks a conceptual replication whether the effect appears in the changed conditions. With "whether the effect is there or not", the result now says when the planned sample size leaves the absence criterion below the chance aimed for, with the size that criterion needs, since a null result at the main criterion's size may be unable to show anything. An extension that adds a changed version of the original condition is told that the replication's sample size covers the original condition alone, that the difference between the versions is an interaction with the original comparison (a three-way interaction for a 2 x 2 original, planned on the three-factor ANOVA card), and that showing an effect disappears needs about four times as many people as finding it.
