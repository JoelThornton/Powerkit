  (one-way, factorial, repeated-measures and three-factor ANOVA, ANCOVA,
  regression, R-squared change, two proportions and contingency tables)
  describe each prior's starting value as "the package default" instead
  of as JASP's. `bayes_robustness()` labels the medium width "Medium (the
